Test Tamil sentences

Up to 10 sentences, one per line, numbers written as words. Gnani Timbre speaks them, we build a clean and a noisy phone-line version, and Prisma transcribes each one raw (F0) and with the KuralCheck fix layer (F3).

Test your own voice

Speak one Tamil sentence the way you normally talk (up to 30 s). It is sent to Prisma as recorded and through a simulated noisy phone line. Nothing is stored.

Score a transcript

Character and word error rate after KuralCheck normalisation, with number checking. Runs on the server, uses no API credits.

Fix a Prisma transcript

Applies the KuralCheck fix layer (format rules such as ₹25 → 25 ரூபாய், plus spelling rules tuned on the dev split). No API credits.

Benchmark results

Headline numbers from the latest KuralCheck run (test split). CER in % with bootstrap 95% CI; n = utterances.
